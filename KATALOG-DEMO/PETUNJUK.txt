KATALOG UNDANGAN DIGITAL (folder mandiri, siap upload)

ISI FOLDER
  index.html                   halaman katalog (jarang diubah)
  assets/js/katalog-data.js    DATA katalog: satu-satunya file yang rutin diedit
  assets/img/og.jpg            foto pratinjau WhatsApp (600x600, di bawah 200 KB)
  assets/img/katalog/          tempat gambar cover opsional
  tools/terapkan-meta.js       memperbarui meta tag index.html otomatis

PERTAMA KALI (sekali saja)
  1. Buat repo baru di GitHub, mis. "katalog-undangan".
  2. Upload ISI folder ini (index.html, assets, tools), BUKAN foldernya.
  3. Aktifkan: Settings > Pages > Branch main, folder / (root).
  4. Isi katalog-data.js:
       baseUrl  -> alamat dari Settings > Pages (tanpa garis miring di akhir)
       whatsapp -> nomor Anda, contoh "6281234567890" (kosong = tombol Pesan hilang)
  5. (Opsional) jalankan:  node tools/terapkan-meta.js
     lalu upload ulang index.html. Ini membuat kartu pratinjau WhatsApp benar.

KALAU ADA VERSI TERBARU (rutin)
  1. Upload undangan versi baru ke repo-nya sendiri, pastikan online.
  2. Buka assets/js/katalog-data.js, salin satu blok { ... } di daftar KATALOG,
     tempel di akhir (sebelum tanda ]), ubah nama, deskripsi, warna, dan demo.
     Jangan lupa koma di antara blok (blok terakhir tanpa koma).
  3. Tambahkan  baru: true  agar tampil label BARU (hapus bila sudah lama).
  4. Upload HANYA file katalog-data.js ke folder assets/js di GitHub > Commit.
  5. Tunggu 1-2 menit, buka katalog dengan Ctrl+F5.

MENGHAPUS / MENYEMBUNYIKAN MODEL
  Hapus blok-nya dari daftar KATALOG, lalu upload katalog-data.js lagi.

PRATINJAU LANGSUNG vs GAMBAR
  Kolom cover kosong  -> kartu menampilkan pratinjau langsung dari alamat demo.
  Kolom cover diisi   -> kartu menampilkan gambar (lebih cepat). Taruh gambar di
                         assets/img/katalog/, contoh: cover: "assets/img/katalog/versi-8.jpg"
  Bila katalog terasa berat dengan banyak model, pakai gambar cover.

CATATAN
  - Alamat demo (kolom demo) saat ini mengarah ke repo undangan-katalog-darkan.
    Ganti ke alamat repo masing-masing versi bila sudah dipisah.
  - Halaman ini sengaja noindex (tidak muncul di Google). Hapus baris
    <meta name="robots"> di index.html bila ingin dicari lewat Google.
